# postingbot

Telegram-бот для канала: перехватывает новые посты и публикует их заново с фирменной подписью
(ссылки на сеть каналов и хэштеги). Поддерживает текст, фото, видео, документы и GIF.

**Стек:** Python 3.10+, aiogram 3 (async).

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="<токен от @BotFather>"
export CHANNEL_ID="-100..."        # ID канала, где бот администратор
python bot.py
```

Бот должен быть администратором канала с правом удалять и публиковать сообщения.
